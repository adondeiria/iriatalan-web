# Copy History

Archivo de iteraciones de copy del sitio iriatalan.com.mx para trazabilidad histórica.

**Convención de naming:** `copy-review-YYYY-MM-DD.docx`

## Archivos

- **`copy-review-2026-05-08.docx`** — Borrador draft que Claude mandó a Iria para revisar el 2026-05-08, antes del rediseño "Luxury Wealth Planning Humanized" del 2026-05-09. Contiene la estructura completa del home (hero, servicios, para quién, planeación con propósito, 3 columnas, 7 silencios, insights, CTA, header, footer). El rediseño posterior aplicó la mayoría del copy con variaciones (H1 cambiado, sección PARA QUIÉN eliminada y luego restaurada el 2026-05-10, Silencio #03 acortado).

## Cuándo agregar a esta carpeta

Cuando recibas un docx/markdown con copy review de Iria que vaya a aplicarse al sitio. Una vez aplicado, mover el original aquí en vez de borrarlo, para tener registro de qué versión inspiró qué commit.

## Cuándo NO agregar aquí

- Documentos de planeación / briefs / presentaciones → `docs/` raíz o `docs/planning/`
- Reportes técnicos / auditorías → `reports/`
- Imágenes / assets → `public/`
